# CODEX.md — настройки работы с проектом myblog.loc

## Контекст проекта

`myblog.loc` — персональный блог и CRM на самописном PHP MVC без Laravel и Yii2.
Проект работает в OSPanel на Windows.

- PHP 8.5.1, Apache, MariaDB.
- Локальный домен: `myblog.loc`.
- Точка входа: `public/index.php`.
- Backend: `app/Core`, `app/Controllers`, `app/Models`, `routes`.
- Шаблоны: `app/Views/frontend` и `app/Views/admin`.
- Frontend: HTML5, SCSS, JavaScript, Bootstrap 5, Vite 5.
- Сборка: `npm run build`.
- Рабочая ветка: `dev`.

## Актуальные правила

Эти правила отражают договорённости с владельцем проекта и имеют приоритет над устаревшими ограничениями в других инструкциях.

1. `config/database.php` разрешено изменять и коммитить.
2. Модальные окна разрешено использовать и в админке, и на публичном сайте.
3. Статичные информационные баннеры разрешены.
4. Каждое пользовательское уведомление должно сопровождаться Toast.
5. Коммитить и отправлять изменения в remote только по явной просьбе пользователя.
6. Комментарии в коде писать на русском языке.
7. После изменений выполнять точечные проверки, соответствующие задаче; полные E2E-прогоны запускать только по необходимости или просьбе пользователя.
8. После отладки проверять `git status` и удалять созданные временные файлы.

## Технические соглашения

- Имена таблиц в SQL формировать через `db_table()` с учётом `DB_PREFIX`.
- PHP-скрипты в окружении Windows запускать через `C:\PHP\php.exe`.
- Production-ассеты подключать через Vite manifest.
- В production-коде не рассчитывать на `window.bootstrap`; использовать ESM-импорты Bootstrap.
- Для редиректа после POST использовать статус `303`.
- Для API соблюдать CSRF-проверки и существующую структуру сессий.
