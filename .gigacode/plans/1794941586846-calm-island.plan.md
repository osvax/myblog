# MyBlog.loc — Обзор проекта

## Архитектура
- **Кастомный PHP MVC фреймворк** (Front Controller в `public/index.php`)
- **Bootstrap**: `app/bootstrap.php` — автолоад, загрузка core-функций
- **Роутер**: `app/Core/Router.php` — RESTful маршруты с параметрами `{slug}`
- **БД**: Singleton PDO через `app/Core/Database.php`
- **Вьюхи**: `app/Core/View.php` — рендеринг с поддержкой тем

## Ключевые компоненты

### Frontend (серверный рендеринг + AJAX)
| Контроллер | Назначение |
|---|---|
| `HomeController` | Главная с featured-статьями/проектами |
| `BlogController` | Блог: архив, категории, статьи, комментарии |
| `PortfolioController` | Портфолио: проекты, фильтрация |
| `OrderController` | Форма заказа с калькулятором |
| `AuthController` | Регистрация/вход/сброс пароля |
| `ProfileController` | Профиль пользователя |

### Admin Panel (27 страниц)
Полноценная админка: Dashboard, CRUD статей/проектов/категорий, заказы, сообщения, чат-консультант, калькулятор, файловый менеджер, редактор шаблонов (CodeMirror), настройки сайта, управление пользователями, меню, кастомные поля, лендинги.

### API (`routes/api.php`)
- `/api/auth/*` — аутентификация админа (login, CSRF, logout)
- `/api/admin/*` — RESTful CRUD для всего контента
- `/api/consultant` — live-chat виджет
- `/api/forms/*` — публичные формы (заказ, обратная связь, комментарий)

## БД (15+ таблиц)
- **Контент**: `articles`, `portfolio_projects`, `categories`
- **CRM**: `orders` (статусы: New/In Progress/Completed/Cancelled)
- **Коммуникации**: `messages`, `consultant_*` (чаты, сообщения, read receipts, typing)
- **Пользователи**: `users` (роли: user/editor/manager/admin, 2FA TOTP), `user_activities`
- **Настройки**: `site_settings`, `landing_pages`, `landing_page_settings`, `custom_fields`, `menus`, `menu_items`

## Ключевые фичи
1. **Блог** — статьи, категории, теги (JSON), комментарии с апрувом и вложенными ответами
2. **Портфолио** — проекты с задачами/решениями/результатами (JSON), скриншоты
3. **Лендинг-билдер** — генерация HTML из настроек (hero, features, about, services, testimonials, contact)
4. **CRM/Заказы** — трекинг с бюджетами/дедлайнами, экспорт, калькулятор (6 типов сайтов, 30+ опций)
5. **Live Chat** — чат-консультант с read receipts, typing indicators, цензурой, email-уведомлениями
6. **Пользователи** — регистрация, роли, 2FA TOTP, профили с аватарами, трекинг визитов
7. **Менеджер файлов** — загрузка/перенос/удаление
8. **Редактор шаблонов** — CodeMirror с подсветкой синтаксиса
9. **CSRF-защита**, maintenance mode с IP-whitelist, session security

## Assets
- **CSS**: `public/css/style.css`, `public/admin/css/admin.css`
- **JS Frontend**: `auth.js`, `blog-search.js`, `consultant.js`, `forms.js`, `order-calculator.js`
- **JS Admin**: ~24 файла (admin.js, article-edit.js, orders.js, templates.js и др.)
- **UI**: Bootstrap 5 + Bootstrap Icons

## Конфиг
- `config/views.php` — активные темы (frontend/admin)
- `config/admin-pages.php` — 27 страниц админки
- `config/public-content.php` — seed-данные (6 статей, 6 проектов)

## Статус
Проект — полноценный CMS/CRM для блога с портфолио, лендинг-билдером и CRM. Готов к дальнейшей разработке.
