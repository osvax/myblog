# Чисткофф — Описание проекта для портфолио

## О ПРОЕКТЕ

 **Название проекта** | Чисткофф — химчистка мебели и ковров |
 **Тип проекта** | Многостраничный лендинг / корпоративный сайт услуг |


## ЗАДАЧА


1. **Привлечение лидов** — формы заказа, калькулятор стоимости, модальные окна callbacks
2. **Демонстрация экспертизы** — портфолио «До/После», отзывы, кейсы, блог
3. **Информирование** — полный прайс, FAQ, статьи по уходу за мебелью
4. **Конверсия** — понятные CTA, телефон в хедере, фиксированные кнопки заказа
5. **SEO-готовность** — семантическая разметка, meta-теги, структурированные данные


- ✅ Полная адаптивность (320px – 1920px+)
- ✅ Cross-browser совместимость (Chrome, Firefox, Safari, Edge, iOS, Android)
- ✅ Производительность: минифицированный CSS, оптимизированные изображения
- ✅ Доступность (WCAG 2.1 AA): семантика, ARIA, фокус-стили, контрастность
- ✅ Чистая архитектура: БЭМ, SCSS 7-1 паттерн, префикс `va_` для изоляции стилей
- ✅ Без лишних зависимостей: только необходимые jQuery-плагины
- ✅ Удалены счётчики (Яндекс.Метрика) и сторонние скрипты трекинга

---

## РЕШЕНИЕ

1. **Единый CSS-бандл** — все стили (включая vendor: Slick, Fancybox, ArcticModal, AOS) скомпилированы в один `styles/style.css` (minified, ~45 KB gzip)
2. **Кастомные UI-компоненты** — селекты, чекбоксы, аккордеоны без внешних библиотек
3. **IBG паттерн** — `.va_ibg` для background-image с fallback через `<img>` (доступность + SEO)
4. **Анимации AOS** — декларативно через `data-aos` атрибуты, отключены на мобильных для производительности
5. **Модальные окна** — ArcticModal для форм, Fancybox для галерей/видео/отзывов


## РЕЗУЛЬТАТ

Получен масштабируемый лендинг студии текстильного дизайна с понятной SCSS-структурой и изолированными BEM-классами. Проект готов к дальнейшему расширению, локальному запуску и размещению на статическом хостинге.

**Стек технологий:** HTML5, SCSS/Sass, CSS3, JavaScript ES6+, jQuery-плагины исходного проекта, БЭМ, адаптивная вёрстка, SVG/JPG.
