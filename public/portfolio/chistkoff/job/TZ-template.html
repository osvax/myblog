1.2 Методологии и стандарты

  • БЭМ命名 — все кастомные классы с префиксом va_ (например: .va_header__logo, .va_btn--primary)
  • Mobile First — медиа-запросы @media (min-width: ...)
  • Design Tokens — все значения (цвета, отступы, шрифты, брейкпоинты) только через SCSS-переменные
  • Доступность (a11y) — WCAG 2.1 AA: семантика, ARIA, фокус-стили, контрастность ≥ 4.5:1, alt-тексты
  • Кроссбраузерность — Chrome 90+, Firefox 88+, Safari 14+, Edge 90+, iOS Safari 14+, Chrome Android 90+
  • Производительность — CSS < 50 KB gzip, JS < 100 KB gzip, Critical CSS инлайн, lazy-loading изображений

3. Детальное описание ключевых компонентов

3.1 Калькулятор стоимости (.va_calculator)

  • Кастомные селекты (.va_select) с ARIA: «Что чистим», «Количество»
  • Чекбоксы доп. опций (.va_checkbox) с ценой в лейбле
  • Кнопка «Добавить ещё заказ» — динамическое добавление блоков
  • Панель цены справа — обновляется в реальном времени
  • Форма справа: Имя, Телефон (маска), Адрес, Дата, Submit
  • Дисклеймер и примечания под формой

3.2 Кейсы «До/После» (.va_mainworks)

  • Slick-слайдер с 1 слайдом, fade-переход
  • Кастомный ползунок сравнения (CSS clip-path + input[type="range"])
  • Лейблы «до чистки» / «после чистки» поверх изображений
  • Кнопка «Все кейсы» ведёт на портфолио

3.3 Слайдеры (Slick Carousel)

БлокНастройки
Акции (.va_discounts__slider)slidesToShow: 1, fade: true, arrows: true, autoplay: false
Отзывы (.va_reviews__slider)slidesToShow: 3 (1024→2, 768→1), arrows: true
Кейсы (.va_mainworks__slider)slidesToShow: 1, fade: true, custom range slider

3.4 Формы и модалки

  • ArcticModal — формы заказа (#modal-callback, #modal-callback-big), триггеры: [data-arcticmodal="..."]
  • Fancybox 3 — галерея отзывов, видео (YouTube iframe), увеличение фото
  • Маска телефона — +7 (999) 999 99 99 (jQuery Masked Input)
  • Валидация — HTML5 (required, type="tel/email") + JS-проверка перед отправкой
  • Отправка — AJAX (FormData), обработка ответов, toast-уведомления

3.5 Анимации (AOS)

  • Глобальные настройки: offset: 250, duration: 1000, easing: "ease-out-cubic", delay: 100, disable: "mobile", once: true
  • Атрибуты: data-aos="fade-up", data-aos-delay="100|200|300..."
  • На мобильных (< 768px) анимации отключены для производительности

4.3 Инпуты и селекты

  • .va_form__input — padding 12px 16px, border 1px solid $va_color-border, radius 8px, transition все 0.3s
  • :focus — border $va_color-primary, box-shadow 0 0 0 3px rgba(primary, 0.2)
  • .va_select — кастомный dropdown, полная клавиатурная навигация (Enter/Space — открыть, ArrowUp/Down — выбор, Escape — закрыть)
  • .va_checkbox — CSS-only стилизация через ::before/::after, анимация галочки

4.4 IBG паттерн (background images)

JS копирует src в background-image контейнера. скрыт через opacity: 0 / position: absolute, но доступен скринридерам и поисковикам.

5. Приёмка работ (Checklist)

5.1 Функциональные проверки

  • Все N страниц открываются без JS-ошибок в консоли
  • Навигация: меню, хлебные крошки, пагинация/LoadMore работают
  • Гамбургер-меню: открывается/закрывается, лок скролла body, фокус в меню
  • Калькулятор: селекты, чекбоксы, динамическая цена, добавление заказов
  • Слайдеры: автоплей (если есть), стрелки, свайп на таче, клавиатура (←/→)
  • Модалки: открытие по триггерам, закрытие (крестик, ESC, оверлей), фокус-трап
  • Формы: валидация, маска телефона, отправка AJAX, обработка успеха/ошибки
  • Анимации AOS: срабатывают при скролле, не дергаются, отключены на мобильных
  • FAQ аккордеон: открытие/закрытие, только один открыт, клавиатура
  • Фильтр новостей: переключение табов, фильтрация карточек (JS или CSS)
  • Кейсы «До/После»: ползунок работает мышью и клавиатурой

5.2 Визуальные проверки (Pixel Perfect)

  • Соответствие макету ±1px на всех брейкпоинтах (320, 480, 768, 1024, 1200, 1440)
  • Шрифты: начертания, размеры, межстрочные интервалы, цвет текста
  • Цвета: primary, secondary, background, border — точно по дизайну
  • Отступы: padding/margin блоков, gap в гридах/флексах
  • Тени, скругления, границы — согласно дизайн-системе
  • Ховер/фокус/актив состояния всех интерактивных элементов
  • Иконки: размер, цвет, выравнивание
  • Изображения: не растянуты, object-fit: cover где нужно, нет артефактов сжатия

5.3 Технические проверки

  • Валидный HTML5 (W3C Validator — 0 ошибок)
  • CSS без ошибок (Stylelint — 0 errors, warnings по согласованию)
  • JS без ошибок в консоли (ESLint — 0 errors)
  • Один минифицированный CSS-файл (styles/style.css), vendor внутри
  • JS бандл (если есть сборка) или раздельные файлы в правильном порядке
  • Шрифты: WOFF2, preload в , font-display: swap
  • Favicon: ICO + PNG (16, 32, 48, 180px)
  • Meta теги: title, description, OG, viewport, charset на каждой странице
  • Нет внешних счетчиков (Яндекс.Метрика, GA) — только по требованию заказчика
  • Печатные стили: скрыты header/footer/модалки/кнопки, корректные разрывы страниц

5.4 Кроссбраузерность и устройства

  • Chrome (последний) — Windows, macOS, Android
  • Firefox (последний) — Windows, macOS
  • Safari — macOS, iOS (iPhone, iPad)
  • Edge (последний) — Windows
  • Режим разработчика: Device Toolbar — все брейкпоинты
  • Реальные устройства: iPhone SE/14, iPad, Samsung Galaxy, Desktop 1920×1080

5.5 Доступность (a11y)

  • axe DevTools / Lighthouse Accessibility — Score ≥ 95
  • Клавиатурная навигация: Tab порядок логичен, фокус виден везде
  • Скринридер (NVDA/VoiceOver): все контент доступен, ARIA корректны
  • Контрастность: текст ≥ 4.5:1, UI ≥ 3:1 (WCAG AA)
  • Alt-тексты: все имеют осмысленный alt
  • Формы: для каждого инпута
  • Язык страницы:

6.2 Формат сдачи

  • Архив — project.zip со всей структурой (html, scss, css, js, fonts, images)
  • Git репозиторий — приватный репо с историей коммитов (опционально)
  • Тестовый деплой — Netlify / Vercel / GitHub Pages / собственный сервер
  • Документация — README.md (запуск, структура, команды), этот ТЗ

6.3 Коммуникация

  • Ежедневные статусы в мессенджере (Telegram/Slack) — что сделано, планы, блокеры
  • Вопросы по макетам — собирать батчами, не по одному
  • Промежуточные демо — по запросу заказчика
  • Финальная демонстрация — скринкаст или живая сессия
