Техническое задание

АГРОПРОСПЕКТ — дилер сельскохозяйственной техники

Перевёрстка многостраничного сайта: SCSS + БЭМ (префикс va_), полная адаптивность, сохранение контента и интерактива

1. Общие сведения

ПроектАГРОПРОСПЕКТ — дилер сельскохозяйственной техники
ТипАдаптивный многостраничный сайт (5 страниц)
ЯзыкРусский
Срок5 рабочих дней
Формат сдачиHTML, CSS, SCSS, JS, изображения, шрифты, скриншоты

2. Стек и ограничения

  • HTML5, SCSS/Sass (Dart Sass), CSS3, jQuery 3.3.1, Owl Carousel, Picturefill;
  • БЭМ с обязательным префиксом va_ для всех проектных классов;
  • исходные изображения и шрифты (PT Sans) проекта сохраняются без замены;
  • библиотеки исходного проекта (lib/) используются без модификаций;
  • CSS собирается в css/main.css.

3. Структура страниц

1. ГлавнаяШапка с контактами и CTA, каталог техники, hero-слайдер (3 слайда), преимущества, три блока презентаций со слайдерами обложек, «Схема работы» (5 шагов), подвал
2. О компанииХлебные крошки, презентация «Всегда впереди!» со слайдером, таблица технических характеристик, два aside-блока с перечнем ценностей
3. ЗапчастиЗаголовок, текстовый блок, карточки преимуществ
4. Импортная техникаЗаголовок, блок с ценой «от 500 000 ₽» и CTA «Запросить предложение», преимущества, таблица характеристик (десктоп + мобильная)
5. Каталог «Зерновые сеялки»Заголовок, сетка из 4 карточек товаров, преимущества

4. Адаптивность

Брейкпоинты: 360 / 480 / 576 / 768 / 992 / 1200 / 1400 / 1921 px.

  • до 768 px — полноэкранное мобильное меню с раскрываемым каталогом внутри;
  • сохранена жидкая типографика оригинала: em на десктопе, vw на планшетах и мобильных;
  • сетки и слайдеры перестраиваются без горизонтального скролла (проверено на 320–1920 px);
  • изображения: object-fit: cover и сохранение пропорций;
  • таблица импорта на мобильных складывается в стек, дополнительно показывается мобильная таблица.

5. SCSS-архитектура

abstracts — переменные, миксины, подключение шрифтов; base — reset и базовые стили; layout — контейнер и сетка; components — 16 компонентов (header, navigation, hero, features, presentation, steps, page, table, footer, modal, form, breadcrumb, burger, common и др.); utils — утилиты; style.scss — точка входа.

6. Интерактивность

  • плавные якорные переходы (включая #contacts в подвале);
  • выпадающий каталог техники (desktop) с закрытием по клику вне;
  • полноэкранное мобильное меню: бургер → оверлей, каталог внутри, Esc, блокировка скролла;
  • слайдеры hero и обложек (Owl Carousel, rewind, стрелки);
  • модальная форма «Заказать звонок» / «Запросить предложение»: динамический заголовок, автофокус, закрытие по Esc / бэкдропу / кнопке;
  • guard на пустых якорях href="#".

7. Приёмка

  • все классы имеют префикс va_ и соответствуют БЭМ;
  • SCSS компилируется без ошибок (dart-sass, без source-map);
  • интерактивы и формы работают на всех страницах;
  • нет ошибок в консоли, битых ассетов и горизонтального скролла;
  • проверены desktop (1920 / 1440 / 1200), tablet (992 / 768) и mobile (390 / 360 / 320);
  • подготовлены 4 скриншота 1200×675 (16:9) для портфолио.
