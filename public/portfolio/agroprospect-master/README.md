# АГРОПРОСПЕКТ — дилер сельскохозяйственной техники

Адаптивный многостраничный сайт дилерского центра сельхозтехники «Агропроспект» (5 страниц). Проект перевёрстан с внедрением SCSS, методологии БЭМ и уникального префикса `va_` для изоляции стилей; весь контент, исходные ассеты и интерактив сохранены.

## 🎯 Особенности

- **Полная адаптивность** — 8 брейкпоинтов: 360 / 480 / 576 / 768 / 992 / 1200 / 1400 / 1921 px, без горизонтального скролла
- **Семантический HTML5** — `header`, `nav`, `main`, `section`, `article`, `table`, `form`, `footer`
- **БЭМ + префикс `va_`** — все проектные классы имеют уникальный namespace
- **Доступность** — ARIA-состояния меню и модалки, `:focus-visible`, закрытие по `Escape`, `alt` у изображений
- **Сохранён стек оригинала** — jQuery 3.3.1, Owl Carousel, Picturefill (без фреймворков и сборщиков)
- **Жидкая типографика** — сохранены em/vw-кегли оригинала, шрифт PT Sans
- **SCSS-архитектура** — 23 модуля: abstracts, base, layout, 16 компонентов, utils

## 🚀 Быстрый старт

### Вариант 1: Открыть локально (без сборки)

```bash
# Просто откройте index.html в браузере
# Или запустите любой статический сервер:
python -m http.server 8077
# затем http://127.0.0.1:8077
```

### Вариант 2: Компиляция SCSS (для разработки)

```bash
# Установка Sass (если не установлен)
npm i -g sass

# Компиляция в CSS
sass scss/style.scss css/main.css --no-source-map

# Или в режиме наблюдения
sass --watch scss/style.scss:css/main.css
```

## 🧩 Интерактивность (js/main.js)

| Функция | Описание |
|---------|----------|
| **Плавные якоря** | Анимированный скролл к `#contacts` и другим якорям, guard на пустых `href="#"` |
| **Каталог техники** | Выпадающий каталог (desktop): toggle по бургеру, закрытие по клику вне, `aria-expanded` |
| **Мобильное меню** | Бургер → полноэкранный оверлей, раскрываемый каталог внутри, `Escape`, блокировка скролла `body` |
| **Слайдеры** | Hero (3 слайда) и обложки презентаций — Owl Carousel, `rewind`, кастомные стрелки |
| **Модальная форма** | Динамический заголовок (`data-form-title`), автофокус на первое поле, закрытие по `Esc` / бэкдропу / кнопке |
| **Сброс состояний** | При выходе из мобильного брейкпоинта снимаются оверлей и scroll-lock |

## ♿ Доступность

- Видимый `:focus-visible` на всех интерактивных элементах
- `aria-label`, `aria-controls`, `aria-expanded` для бургеров и меню
- Модальное окно: `role="dialog"`, `aria-modal`, `aria-labelledby`
- Семантическая разметка (`<main>`, `<nav>`, `<section>`, `<button type="button">`)
- `alt` для всех контентных изображений
- Градиент-оверлей на hero для контраста белого текста

## 🎨 Дизайн-система (SCSS переменные)

```scss
$va-c-primary:    #18965e;   // фирменный зелёный
$va-c-accent:     #d6b603;   // hover-состояние
$va-c-bg:         #f5f5f5;   // фон страницы
$va-c-footer:     #21262e;   // фон подвала
$va-font-main:    'PT Sans'; // основной шрифт
$va-container-max: 50em;     // 1200px при базовом кегле
$va-bp-sm:        768px;     // мобильная граница
```
