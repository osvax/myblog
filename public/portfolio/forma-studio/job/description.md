# FORMA STUDIO — Лендинг архитектурной студии

**Описание работы для портфолио**

---

## О ПРОЕКТЕ

**FORMA STUDIO** — адаптивный лендинг архитектурного бюро, разработанный по индивидуальному дизайну в Figma. Проект демонстрирует портфолио студии, перечень услуг, этапы работы с клиентом и предоставляет две точки конверсии: подписку на каталог проектов и форму заявки на консультацию.

**Ключевые особенности:**
- Пиксель-перфектная вёрстка по макету 1920×7525 px с соблюдением всех визуальных отступов, типографики и декоративных элементов
- Полностью адаптивный интерфейс (7 брейкпоинтов: 320–1920 px) без горизонтального скролла на любом устройстве
- Две интерактивные формы с клиентской валидацией, инлайн-ошибками и success-уведомлениями (без бэкенда)
- Горизонтальная карусель проектов с поддержкой свайпа, drag-and-drop мышью, клавиатурной навигацией и пагинацией
- Reveal-анимации при скролле (IntersectionObserver, stagger 60 мс) с респектом `prefers-reduced-motion`
- Доступность WCAG 2.1 AA: семантическая HTML5-разметка, ARIA-атрибуты, фокус-стили, skip-link
- Чистый стек: HTML5 + CSS3 (Custom Properties, Grid, Flex, clamp) + Vanilla JS (ES2017+) + Sass — без сборщиков и зависимостей
- Исходники SCSS (21 файл, модульная структура) переданы заказчику для дальнейшего масштабирования дизайн-системы

**Целевая аудитория:** частные заказчики (строительство/ремонт), застройщики, дизайнеры интерьеров, архитектурные бюро-партнёры.

**Бизнес-задача:** презентация экспертизы студии, генерация лидов через формы, демонстрация портфолио реализованных объектов.

## РЕШЕНИЕ

### 1. Анализ макета
FIG-макет (Figma) — одностраничный растр 1920×7525 px. Дизайн разобран визуально на 7 смысловых срезов, все изображения экспортированы в 2× качестве (Retina-ready).

### 2. Структура страницы (8 секций)
1. **Hero** — главный экран с фиксированной шапкой, H1, описанием и CTA-кнопкой;
2. **Services** — 4 строки услуг с разделителями на тёмном фоне;
3. **Projects** — горизонтальная карусель из 4 карточек (4-я обрезана краем, как в макете), навигация стрелками, свайп, drag мышью;
4. **Steps** — 8 этапов работы с нумерацией и вертикальной линией + фото интерьера;
5. **Catalog** — заголовок и фото слева, форма подписки с чекбоксом согласия справа;
6. **Gallery** — сетка 4×2 интерьеров с зазором 20 px;
7. **CTA** — баннер с фоновым фото, полупрозрачной панелью и формой заявки;
8. **Footer** — 5 колонок: логотип, навигация, услуги, контакты, адрес.

### 3. Адаптивность (6 брейкпоинтов)
1920 / 1440 / 1200 / 1024 / 768 / 480 / 320 px.
- Контейнер 1720 px, боковые отступы `clamp(20px, 5.2vw, 100px)`.
- Навигация ≤1024 px — бургер-меню с полноэкранным оверлеем.
- Карусель: 3 карточки ≥1200 px, 2 карточки 768–1199 px, 1 карточка ≤767 px.
- Галерея: 4 / 2 / 1 колонка.
- Все шрифтовые размеры — `clamp()` для плавного масштабирования.

### 4. Интерактив (Vanilla JS, ~300 строк)
- Фиксированная шапка: фон и тень при `scrollY > 40 px`;
- Бургер: открытие/закрытие, блокировка скролла `body`, закрытие по `Esc` и по ссылке;
- Плавные якоря с учётом высоты шапки;
- Карусель: кнопки Prev/Next (disabled в крайних позициях), свайп, drag мышью;
- Reveal-анимации через `IntersectionObserver` (stagger 60 мс);
- Валидация формы каталога: e-mail + чекбокс, инлайн-ошибки, сообщение об успехе;
- Валидация CTA-формы: e-mail, инлайн-ошибка, успех с автоскрытием через 8 с;
- Подсветка активного пункта меню при скролле.

### 5. Изображения
16 файлов, экспортированные из Figma: `hero.jpg`, `project-1..4.jpg`, `steps-interior.jpg`, `catalog.jpg`, `gallery-1..8.jpg`, `cta-house.jpg`.
4-я карточка проектов собрана зеркальным отражением `gallery-2.jpg`.

### 6. SCSS-источники (папка `scss/`, 21 файл)
- `abstracts/_variables.scss` — все дизайн-токены (цвета, шрифты, сетка, брейкпоинты);
- `abstracts/_mixins.scss` — `mq()`, `card-width()`;
- `base/` — сброс, типографика, анимации, CSS-переменные;
- `components/` — по файлу на блок (header, hero, services, projects, steps, catalog, forms, gallery, cta, footer);
- `utils/_responsive.scss` — весь адаптив в одном месте;
- Компиляция: `sass scss/style.scss css/style.css --style=expanded`.
