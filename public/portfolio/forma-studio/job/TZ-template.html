2. ВХОДНЫЕ ДАННЫЕ

2.1. Исходные материалы

  • Готовый лендинг в папке forma-studio/ (index.html, css/style.css, js/app.js, images/, scss/)
  • Макет в PDF: Architecture.pdf (десктоп 1920px)
  • Изображения: вырезаны из макета в исходном качестве (hero.jpg, project-1..4.jpg, steps-interior.jpg, catalog.jpg, gallery-1..8.jpg, cta-house.jpg)
  • Шрифт: Inter (Google Fonts, веса 300, 400, 500)
  • Тексты: полностью на русском языке (переведены с украинского)

2.2. Существующая функциональность (обязательно к сохранению)

  1. Шапка — фиксированная, фон при скролле, бургер-меню (< 1024px)
  2. Hero — фоновое изображение с градиентом, H1, текст, CTA-кнопка
  3. Услуги — 4 строки в тёмной теме с разделителями
  4. Проекты — карусель 4 карточек (стрелки, свайп, drag мышью, scroll-snap)
  5. Этапы работы — 8 шагов с нумерацией и вертикальной линией + фото справа
  6. Каталог — фото + форма с e-mail и чекбоксом согласия
  7. Галерея — сетка 4×2 изображений
  8. CTA-баннер — фоновое фото, полупрозрачная панель, форма заявки
  9. Подвал — логотип, 2 колонки навигации, контакты, адрес, часы работы

2.3. Интерактивные сценарии

  • Плавный скролл к якорям с учётом высоты шапки
  • Бургер-меню (открытие/закрытие, ESC, клик по ссылке, фокус-ловушка)
  • Карусель проектов: кнопки prev/next, drag-события, touch-свайп, обновление стрелок
  • Reveal-анимации при скролле (IntersectionObserver, каскадная задержка)
  • Валидация форм: email regex, чекбокс, инлайн-ошибки, сообщение об успехе
  • Подсветка активного пункта меню при скролле

3. ТРЕБОВАНИЯ К РЕАЛИЗАЦИИ

3.1. Методология и архитектура

  • ✅ SCSS — препроцессор (Dart Sass), компиляция в css/style.css
  • ✅ BEM — именование классов: .va-block__element--modifier
  • ✅ Префикс уникальности va_ — во всех CSS-классах, CSS-переменных (--va-*), Sass-переменных ($va-*), миксинах (va-*)
  • ✅ Модульная архитектура 7-1: 
    scss/
├── abstracts/   # переменные, миксины, функции
├── base/        # reset, typography, animations, root variables
├── components/  # независимые UI-блоки
└── utils/       # responsive (все @media в одном файле)

3.2. Дизайн-токены (abstracts/_variables.scss)

КатегорияПеременные (примеры)
Цвета$va-c-dark, $va-c-black, $va-c-white, $va-c-text, $va-c-muted, $va-c-line-light, $va-c-line-dark, $va-c-error
Сетка$va-container-width: 1720px, $va-gutter: clamp(20px, 5.2vw, 100px), $va-card-gap: 20px
Типографика$va-font-family: "Inter", ...
Анимации$va-ease: cubic-bezier(0.4, 0, 0.2, 1)
Брейкпоинты$va-bp-xl: 1440px, $va-bp-lg: 1200px, $va-bp-md: 1024px, $va-bp-sm: 768px, $va-bp-xs: 480px

3.3. CSS-переменные (base/_root.scss)

Все токены продублированы в :root с префиксом --va-* для runtime-доступа из JS.

3.4. Базовые утилиты (base/)

  • .va-container — резиновый контейнер с max-width: var(--va-container), padding: 0 var(--va-gutter)
  • .va-section — вертикальные отступы секций (padding: 120px 0)
  • .va-section-title — заголовок секции (clamp, uppercase, weight 300)
  • .va-btn — базовая кнопка с модификаторами --light / --dark
  • .va-reveal / .is-visible — анимация появления (opacity + translateY)
  • .va-visually-hidden, .va-skip-link — a11y-утилиты

3.6. Адаптивность (utils/_responsive.scss)

Все @media (max-width: ...) в одном файле, порядок: 1440 → 1200 → 1024 → 768 → 480.

БрейкпоинтКлючевые изменения
≤1440Уменьшенные отступы секций, футер 4 колонки
≤1200Карточки проектов 2 в ряд, шаги — в 1 колонку, галерея gap 14px, футер 2 колонки
≤1024Бургер-меню, скрытие телефона в шапке, каталог/галерея/ктa — мобильный layout
≤768Секции 64px, hero min-height 620px, услуги в 1 колонку, карточки 86%, шаги компактнее, формы на всю ширину
≤480Галерея gap 10px, карточки 92%, gap карусели 16px

3.7. JavaScript (js/app.js)

  • Паттерн: IIFE, "use strict", кэширование DOM-элементов
  • Нет зависимостей — чистый Vanilla JS (ES6+)
  • Модули: header scroll, burger, smooth scroll, carousel, reveal, forms, active nav
  • Доступность: aria-expanded/label/controls, focus management, ESC, passive listeners
  • Производительность: passive: true для scroll, IntersectionObserver вместо scroll-листенеров для ревеала

3.8. Качество кода

  • Семантическая HTML5-разметка
  • alt на всех изображениях (описательные)
  • loading="lazy" для изображений ниже фолда
  • aspect-ratio на медиа-контейнерах (предотвращение CLS)
  • prefers-reduced-motion — отключение анимаций
  • :focus-visible — видимый фокус для клавиатуры
  • Контрастность текста ≥ 4.5:1 (WCAG AA)
